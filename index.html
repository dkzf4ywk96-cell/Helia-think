HELIA THINK 사용 가이드

정답을 받기보다 판단 과정을 남기는 데 집중해.

1. 먼저 생각하기기사나 주제를 읽고 AI를 보기 전에 내 판단부터 적어.
2. 여섯 단계로 구조화사건 → 원인 → 영향 → 확인 → 결론 → 반증 순서로 연결해.
3. 헬리아 점검약한 고리, 확인할 숫자, 반대 가설을 보고 한 번 더 수정해.
4. 복기하기며칠 뒤 실제 결과와 당시 판단을 비교해서 틀린 이유를 남겨.
